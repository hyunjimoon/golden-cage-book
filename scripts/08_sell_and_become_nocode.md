# 8. 「그래서 이 책은 됐나요」 — 🤚 팔림과 됨

**이 자리에 .py 가 없다.** 아홉 중 가장 급한 구멍이라 가장 길게 적는다.

| | |
|:--|:--|
| 자는 있나 | 있다 — 창업에는 두 확률이 있다. **팔릴 확률**과 **만들어질 확률.** 크게 약속하면 팔릴 확률이 오르고 만들 확률이 내린다. 그 둘을 약속 수준 위에서 곱해 더한다 |
| 코드는 있나 | 없다. 숫자가 `probability_evolution.html` 에 **손으로 박혀 있다** |
| 실측 | 166일 · 78개 사건 · 끝점에서 **팔림 86 · 됨 89.** 병목은 팔림이다 |
| 진짜 문제 | 이 값은 **전부 안에서 잰 것이고 밖에서 온 지적은 0건이다.** 게다가 숫자가 화면에 박혀 있어 밖의 값이 와도 넣을 자리가 없다 |
| 다음 한 칸 | 사건 78개를 먼저 파일 하나로 내린다. 그래야 밖에서 온 한 건이 들어올 자리가 생긴다. 그래프는 그다음이다 |

**이 구멍과 열번째 칸의 「손 0」은 같은 구멍이다.** 본 것·궁리한 것·뛴 것은 쌓였는데 밖으로 나간 것이 없다.
