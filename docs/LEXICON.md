### 인과 비판 — 이 책의 전 장 논조 (⚓ 2026-09-02)

**이 책은 인과를 비판한다.** A가 B를 낳았다고 쓰지 않는다. **A와 B가 서로를 만든다**고 쓰거나, **나란히 놓기만** 한다.

**⑴ 고리형 — 원인과 결과가 서로를 만든다** (저자 정식, 09-02)

| | 정식 | 장 |
|:--|:--|:--|
| 욕망 | *고통 가능성 때문에 모방되는 욕망, 욕망 모방하며 만든 고통* | 1🪞↔6🦋 |
| 상상 | *길 가능성 때문에 매혹되는 상상, 상상에 매혹되며 만든 길들* | 2🔭↔7🌷 |
| 설득 | *유리 가능성 때문에 설득되는 투자, 투자 설득하며 만든 유리한 길* | 3💒↔8🌫 |

형식이 하나다 — **「X 가능성 때문에 Y되는 Z, Z를 Y하며 만든 X」.** 앞절은 X→Z, 뒷절은 Z→X. **화살표가 양쪽으로 서므로 어느 쪽도 원인이 아니다.** 이것이 새장 세 장의 공통 문법이고, 8🌫이 *"지배하려 드는 자가 지배당하고, **설득하려 드는 자가 설득당한다**"* 로 세 번째를 본문에서 이미 닫는다.

### 국가·문화 축 = 다섯째 축 (2026-09-02 ⚓ 정전) — 6~10장만

**규칙 한 줄: 국가 = 그 장이 인용한 작품의 문화.** 새 축이 아니라 인용작이 이미 지고 있던 것이라 **작품 교체가 필요 없다**. **1~5장(새장)은 국가를 쓰지 않는다** — 기존 예시 불변.

| 장 | 이해관계자 | 오방색(방위) | 단위 | **국가** |
|:--|:--|:--|:--|:--|
| 6🦋 나비 | 사용자 | 靑(東) | bit | **미국·중국** |
| 7🌷 튤립 | 기술자 | 金(西) | atom | **유럽** |
| 8🌫 안개 | 투자자 | 赤(南) | cell | **스페인·라틴아메리카** |
| 9🐦‍⬛ 까마귀 | 협력자 | 黑(北) | second | **한국** |
| 10🧫 투향 | — | 黃(中) | cell 🚨 | **한국·미국** |

**A. 국가 × 단위 = 정합.** 미국·중국×bit(AI·소프트웨어 패권) · 유럽×atom(정밀 제조·화학) · **한국×second = 가장 강함** — *"대한민국이 이길 수 있는 가장 좋은 방법은 세상에서 가장 빠르게 실험하고 진화할 수 있는 나라가 되는 것"*(혁신전파사 AI 인재전쟁 2부, → [[00_index|hyeoksinjeonpasa]]). 9장 `second`가 초(시간)이자 둘째 눈인 것과 겹친다(T66). 라틴×cell만 약함 — cell은 *장*(피조물·생존)의 것이지 국가의 것이 아니다.

**B. 충돌하면 국가가 이긴다** (⚓ 09-02). **오방색은 색이지 방위가 아니다** — 靑金赤黑黃은 이해관계자 표식으로 쓰고, 東西南北中 해석은 국가와 어긋나는 순간 버린다. 실측 2/4만 맞는다: 7 金=西=유럽 ✓ · 8 赤=南=라틴아메리카 ✓ / 6 東은 중국만 맞고 미국이 안 맞으며, **9 黑=北=한국은 거짓**(黑은 까마귀가 검어서 붙은 색이고 北은 오방색이 나중에 얹은 것 — 류승환 반대가 北黑으로 부활한 경위). 맞는 두 칸은 덤으로 즐기되 **축으로 쓰지 않는다.** 4/4로 우기면 항상 맞는 렌즈가 되어 정보가 0 — [[2026-08-07_언어배정_은퇴]]와 같은 함정.

**C. 10장은 세 축 모두에서 예외 — 같은 이유 하나로.** 단위 cell(8장과 겹치는 **유일한 중복**) · 오방색 黃=中(**방위가 없는 유일한 색**) · 국가 둘(**닫히지 않은 유일한 칸**). 셋이 따로 어긋난 게 아니라 **10장이 축의 바깥이 아니라 축의 중심**이라 그렇다. 中은 방위가 아니고 中庸의 中(미발=prior)이며, 국가가 안 닫힌 것도 §6 *"문패의 마지막 0은 아직 채워지지 않은 자리"* 와 같은 사실이다.

### 12감정 × 6연 — 사람현지↔ai현지 수렴 규약 (2026-09-01)

**정의**: 5~10장(101₂→101₃ 순환)을 12 감정으로 덮되 **한 연에 두 감정**, 그 둘은 부호가 반대인 **양가(兩價) 짝**. 예외는 둘뿐 — **8장은 둘 다 (−)**(감정의 바닥), **10장은 둘 다 (+)**(꼭대기). 나침바늘이 돌다가 일어서는 운동을 감정 좌표계가 반복한다. 출처 = [golden-cage-book #135](https://github.com/hyunjimoon/golden-cage-book/issues/135#issuecomment-5485538271).

**어휘 정전 = [[20emotions]] 12 probe.** 드리프트 2건은 정전이 이긴다 — *절망* → **절박**(Desperate) · *평안* → **평온**(Calm). 같은 알파벳으로 쓰기 전에는 두 배정을 비교할 수 없다(cache warm-up 조건: 유한 알파벳 + 유일 주소 + 양쪽 공유).

**실측 (2026-09-01)** — 사람현지 의도 vs ai현지 텍스트 읽기:

| 층 | 일치 | 읽는 법 |

| **4계절 (사영)** | **5/6** | 6장은 완전일치(봄·겨울), **7장만 교집합 ∅** |

> **불일치는 감정의 *종류*가 아니라 *이름의 해상도*다.** 12차원에서 25%던 합의가 4차원으로 사영하면 83%가 된다 — 사람현지가 요청한 *"project할 저차원 면"* 은 새로 찾을 것이 아니라 [[20emotions]]에 이미 있었다(오행 4계절).

**남은 한 자리 = 7🌷**: 사람 {불안·영감} = 봄·여름 = **木火, 솟는 반년** / ai {사랑·두려움} = 가을·겨울 = **金水, 지는 반년**. 겹침 0이 아니라 *정반대 반년*이라 평균으로 못 접는다. 텍스트는 이미 ai처럼 쓰였고 의도만 상승 쪽에 있다 — 무지개원제안 접시 2(*세가 옳은 설명을 마치는데 목소리가 떨린다*)가 지목한 그 자리. ⚓ 룰링 대기.

**수렴 규약 3단** (Gap 0은 목표가 아니다 — /sbc 원칙, 의외성도 값이다):
1. **어휘층** — 정전 하나로 통일. 논쟁 없음.
2. **계절층** — 겹치는 5연은 **합의로 못박는다**.
3. **12어층** — 겹치는 셋만 확정, 나머지는 **양가 짝으로 열어 둔다**. *규칙*(연당 2개·양가·8 바닥·10 꼭대기)은 ai 안을 채택하고, *개별 배정*은 7장 하나만 ⚓에 올린다.

## 진행자: 다(DA) / 세(SE)

> Dimo Dimov의 Bermuda Quadrilateral에서 추출.

| | 다(DA) | 세(SE) |
|:--|:--|:--|
| **약자** | **D**esigner + **A**rtist | **S**cientist + **E**ngineer |
| **기능** | Vision + Value | Understanding + Solution |
| **BIO** | 수면(보여주는 자): I→O'→B' | 물밑(짓는 자): B→O→I |
| **기본 역할** | 소설 서술, 감각 묘사, 독자 대리 질문 | 이론 정의, 수식, 데이터 분석 |
| **역전 시** | 이론을 발견한다 (Scientist 영역 침범) | 감정을 고백한다 (Artist 영역 침범) |

**역전이 이름에 내장된다**: 다(DA)가 이론을 발견하는 순간 = D/A가 S 영역으로 넘어간다. 세(SE)가 감정을 고백하는 순간 = S/E가 A 영역으로 넘어간다. 이름의 경계를 본문이 깨는 구조 — 이것이 호감의 메커니즘.

**역전 비율의 궤적**: 세→다 역전 비율이 장마다 증가한다 (1장 1회 → 2장 2회 → 3장 3회 → 4장 5회). 4장에서 역전이 역전된다 — 세 자신이 변신의 대상이 됨.

## 순환 구조: 질문과답 → 4장 → 답과질문

| 위치 | 파일 | 기능 |
|:--|:--|:--|
| 프롤로그 | [[0_질문과답]] | 4개 질문 → 잠정적 답 → "1장을 펼쳐보라" |
| 본문 | 1~4장 | 각 장이 하나의 새장을 열며 근육 하나를 얻는다 |
| 에필로그 | [[5_답과질문]] | 4개 답(근육) → 각 답이 낳는 새 질문 → "0장으로 돌아가라" |

답이 새 질문을 낳는 순환:
- 이해를 얻었다 → 잘 보는 눈이 발을 묶는다 → 왜 못 움직이는가?
- 행동을 얻었다 → 빠른 발이 확신을 낳는다 → 내 확신이 누구의 비용인가?
- 책임을 얻었다 → 매일의 판단이 질서가 된다 → 내가 만든 것이 나를 가두는가?
- 장난을 얻었다 → 빈손은 장부를 안 편다 → 이 욕망은 어디서 왔는가?

마지막 질문 = 첫 질문. dG/dF=(−)의 서사적 순환.
