# 슬픔은 문학의 본질인가

> 처음 쓴 자리 — [#78](https://github.com/hyunjimoon/golden-cage-book/issues/78#issuecomment-6554521121) · 본문에서 만나는 자리 — **3 스테인굴레스**

---

해당 과목 교수가 그 과목 실전에 가장 약하다는 경영대 웃픈 농담이 있다. 마케팅 가르쳐도 해당 수업 마케팅 잘 못하는 교수부터 로비 가르쳐도 로비 한번도 안해봤다는 교수까지, 농담을 확인해준 사례도 있고.

칭찬보단 비평 기능에 특화된 엄마는 한강 작가 작품들이 한국문학 잘 대표 못한다 생각하신다. 흘려들었던걸 기억해보면 슬픔과 역사 트라우마에 너무 초점 맞춰져있어 그러시는 듯하다. 

문학이 삶의 반영이라면, 일반 사람들이 살아가며 하는 생각과 느끼는 감정의 비율이 문학에 기록된 생각과 감정과 통계적으로 유사해야 하지 않나? 생각의 종류보단 감정의 종류가 더 적어 감정을 우선 이야기해보면, 문학의 희노애락 네 정서가 균형적이길 바라는데, 관찰되는 문학작품들 주 감정이 슬픔인 현상을 
```

관찰되는 문학작품들 주 감정이 슬픔인 현상

i) desirable? 바꾸는게 바람직한지 
ii) feasible? 바꿀 가능성이 있는지 
iii) viable? 바꿀 유인 가진 사람/집단 누굴지 
```

궁금하다. 문학의 감정균형을 향하는게 바람직하고 가능성 있다면 viability최대화를 위해 잠재 생산자, 평가자, 사용자 집단의 타겟팅과 로드맵핑이 중요해보인다. 번역하면 작가 풀, 편집자 풀, 독자 풀(pool)의 공동성장. 한 사람이 여러 풀에 몸 담을 수 있다.

본질과 truth의 존재 잘 안 믿기에, "The truth is rarely pure and never simple"라는 오스카 와일드 말 잠깐 믿어보면, b\~d끼리 강화하며 a인척 하고 있나? 의심도 든다.🎟️ 

```
슬픔은
a. 문학의 본질
b. 쓰는 자들의 편향
c. 기획/평가하는 자들의 편향
d. 읽는 자들의 편향
```

a가 진실일 가능성 높이는 원인 상상
1. 애초에 슬픈 감정에 예민한 사람들이 문학 선택하는 선택편향

2. https://github.com/hyunjimoon/golden-cage-book/issues/147#issuecomment-5845378666 의 감정표현의 독 배출효과

3. https://github.com/hyunjimoon/golden-cage-book/issues/147#issuecomment-5845378666 의 생존편향 "부정 감정이 생존 확률을 올린다. 미워하면 경계태세가 되고, (적당히) 걱정하면 실패 확률이 준다. 그리고 독자도 남의 기쁨엔 별 감흥이 없고 힘듦을 이겨내는 이야기를 듣고 싶어 한다."

4. 승화 🎟️🎟️

쓰고보니 오스카 와일드 말 좀 더 믿어봐도 되겠다. 


편지와 이야기 주제로 한 노래는 왜 슬픈 감정이 많은지, 세문전에서 사랑은 왜 (현실과 다르게?) 대부분 파국으로 끝난다 하는지 그 원인을 따져보고 개선의 효용과 가능성을 상상하다 여기까지 흐른 글. 첫번째 단락을 쓴 이유가 기억에서 증발한 줄 알았는데, 여러 분야에서 공통적으로 관찰한 현상 "생각과 행동의 괴리"가 보편적 진리라면, 생각창고 문학은 행동에 실패한 자들의 슬픔 저장소라 설득하려던 기억이 응결돼 돌아온다. 스타트업 성공률, 즉 도전 성공률이 10%란 수치가 탈피하는 생산자 나비 이미지와 겹치며, 문학이란 벌판에 90% 번데기 사체와 10% 껍데기가 뒹구는 모습이 보인다.

만약 현재 문학계 사람들 대다수가, 문학이 "도피처 위안"의 정체성 갖길 원한다면 감정균형 향한 내 바람의 실현을 위해 타임라인을 길게 잡고 지속적인 노력할 마음의 준비가 필요하다. "Science progresses one funeral at a time"라는 말이 있듯 \~계의 변화는 빠를땐 빠르지만 느릴땐 느리다.🎟️🎟️🎟️ 

출판계에 내 노력 투자가치가 있다 생각했던 이유는, AI기술에 위협받는 최전선 분야로서 생존을 위한 몸부림이 변화를 가속시킬 수 있다 봤기 때문. **Inflections(변곡점)**, **Insights(통찰)**, **Founder-Future Fit(창업자-미래 적합성)** 을 강조한 Maples.Jr <패턴 브레이커> 🎟️🎟️🎟️🎟️

1. 영감
마케팅과 운동의 차이는 전자가 실용 이유에만 집중 vs 후자의 미학적 이유 영감 (주: 여기서 실용은 좁은 의미의 평가기준 고정된 효율 추구 의미로 쓰임. 나는 미학적 영감으로 자기생산하는 행위도 실용으로 넓게 본다. 미의식 모댈 확장에 따라 평가기준 바뀌므로 효율을 넘어 효과 추구)

마케팅 vs 운동
| 마케팅 | 운동 |
|:---|:---|
| 타겟 → 프로그램 → 전환 | 신념 → 동원 → 공동 창조 |
| 실용적 이유로 설득 | 미학적 이유로 영감 |
| "왜 우리가 더 나은가" | "왜 세상이 달라져야 하는가" |


2. 영웅
맞춤형 영웅서사화: "창업자는 오비완이지 루크가 아니다. 초기 신봉자가 영웅이다"

예1: 청중별 맞춤 서사
| 청중        | 그들의 "영웅 여정"       |
| :-------- | :---------------- |
| **투자자**   | 100배 수익 + 리스트 등재  |
| **초기 고객** | 중요 문제 해결 + 사내 인정  |
| **초기 직원** | 의미있는 일 + 정치 없는 환경 |

예2: 영웅 서사 구조 - lyft 예시
```
1. 평범한 세계 (택시 형편없음)

3. 거부 → 극복 (핑크 콧수염으로 두려움 감소)
4. 도구/마법 (앱, 지도, 알고리즘)
5. 동료 발견 (운전자 커뮤니티)
6. 변환된 귀환 (새로운 이동 방식)
```
