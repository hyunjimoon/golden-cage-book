## 📐 서사확률과정 판독 — M. Butterfly (「투향」 6장 · 전집 밖·희곡)

> 시뮬레이션을 시뮬레이션으로 유지한다 — 1장 거울의 구조를 뒤집어 쓴 판.

| | |
|:--|:--|
| **배경 Ω** | 오리엔탈 환상이 유통되는 냉전 |
| **인물 (µ,σ)** | 송 = 시뮬레이션 유지(µ와 σ를 스스로 쥔다) / 갈리마르 σ=0 |
| **사건 τ** | 법정의 탈의 — 그 자리서 판정된다 |
| **구성 𝓕** | 𝓖(갈리마르) ⊊ 𝓕(송)가 20년. 마담 보바리와 같은 형태, 뒤집힌 부호 |
| **문체 dQ/dP** | 같은 몸에 얹힌 두 측도 |
| **주제** | 시뮬레이션을 믿음으로 붕괴시키지 않기 |

**1↔6 거울** — 엠마는 *모르고* 입고 송은 *알면서* 입는다. 같은 재질(거울), 다른 광원.
